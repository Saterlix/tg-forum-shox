# tg-forum-shox Telegram bot

## Запуск

1. Убедитесь, что установлен Python 3.10 или новее.
2. Проверьте настройки в `.env`.
3. Запустите:

```powershell
python bot.py
```

Бот работает через long polling и сам создаст SQLite-базу `bot.sqlite3`.

## Облачный запуск

Проект готов для Render Worker через `render.yaml` или для любого Docker-хостинга через `Dockerfile`.

В облаке нужно задать переменную `BOT_TOKEN` вручную, чтобы токен не попадал в репозиторий.

## Vercel webhook

Для Vercel бот работает через `/api/webhook`.

После деплоя нужно задать webhook:

```text
https://api.telegram.org/bot<token>/setWebhook?url=https://<vercel-domain>/api/webhook&secret_token=<WEBHOOK_SECRET>
```

## Важно по каналам

Для проверки подписки бот должен быть добавлен в канал/группу, которая указана в `REQUIRED_CHANNELS`.
Если каналы приватные, лучше заменить `CHANNEL_LINKS` на реальные invite-ссылки.

## Админ-панель

Команда:

```text
/admin
```

Супер-админы из `.env` не показываются в списке админов и статистике, их нельзя снять через панель.

## Ответ пользователю

Когда пользователь пишет боту, сообщение копируется владельцу. Чтобы ответить конкретному человеку, владелец должен ответить прямо на это скопированное сообщение.
